# OpenHands Software Agent SDK

The OpenHands Software Agent SDK is a set of Python and REST APIs for **building agents that work with code**. It provides a composable and extensible foundation for creating production-ready AI agents that can perform complex software engineering tasks.

<img 
  src="https://raw.githubusercontent.com/OpenHands/docs/main/openhands/static/img/logo.png" 
  alt="OpenHands Logo" 
  width="200"
/>

## What Can You Build?

The OpenHands SDK enables you to create agents for:

- **One-off tasks**: Building READMEs, generating documentation, creating test files
- **Routine maintenance**: Updating dependencies, refactoring code, fixing bugs
- **Major projects**: Multi-agent architectures, complex refactors, and rewrites

## Architecture Overview

The SDK is organized as a Python monorepo with four main packages:

| Package | Description | Path |
|---------|-------------|------|
| `openhands-sdk` | Core SDK functionality (Agent, LLM, Conversation, Tools) | `openhands-sdk/` |
| `openhands-tools` | Built-in tools for agents (file editor, terminal, etc.) | `openhands-tools/` |
| `openhands-workspace` | Workspace management (local and Docker-based) | `openhands-workspace/` |
| `openhands-agent-server` | REST/WebSocket server for remote agent control | `openhands-agent-server/` |

## Quick Example

Here's a minimal example of using the SDK:

```python
import os
from openhands.sdk import LLM, Agent, Conversation, Tool
from openhands.tools.file_editor import FileEditorTool
from openhands.tools.terminal import TerminalTool

# Configure LLM
llm = LLM(
    model="anthropic/claude-sonnet-4-5-20250929",
    api_key=os.getenv("LLM_API_KEY"),
)

# Create agent with tools
agent = Agent(
    llm=llm,
    tools=[
        Tool(name=TerminalTool.name),
        Tool(name=FileEditorTool.name),
    ],
)

# Start a conversation
conversation = Conversation(agent=agent, workspace=os.getcwd())
conversation.send_message("Write 3 facts about the current project into FACTS.txt.")
conversation.run()
```
